This repository contains some of scripts that I used for creation tables, charts and maps for Wikipedia. The scripts are created inside the computational notebook Jupyter. You can freely use and modify this code to create similar things. I recommend to pay attention to recently updated folders.

Scripts for [Australia](https://www.abs.gov.au/statistics/people/population/life-expectancy/latest-release), [Canada](https://www150.statcan.gc.ca/t1/tbl1/en/tv.action?pid=1310083701), [Finland](https://pxdata.stat.fi/PXWeb/pxweb/en/StatFin/StatFin__kuol/statfin_kuol_pxt_12an.px), [Italy](https://demo.istat.it/tavole/?t=indicatori), and [United Kingdom](https://www.ons.gov.uk/peoplepopulationandcommunity/healthandsocialcare/healthandlifeexpectancies/bulletins/lifeexpectancyforlocalareasoftheuk/between2001to2003and2021to2023) will be uploaded than the statistical agencies of these countries provide data for the next period.
