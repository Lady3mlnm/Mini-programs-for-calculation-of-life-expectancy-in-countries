This repository contains some of scripts that I used for creation tables, charts and maps for Wikipedia. The scripts are created inside the computational notebook Jupyter. You can freely use and modify this code to create similar things. I recommend to pay attention to recently updated folders.

Scripts for [Canada](https://www150.statcan.gc.ca/t1/tbl1/en/tv.action?pid=1310083701), [Finland](https://pxdata.stat.fi/PXWeb/pxweb/en/StatFin/StatFin__kuol/statfin_kuol_pxt_12an.px), and [United Kingdom](https://www.ons.gov.uk/peoplepopulationandcommunity/healthandsocialcare/healthandlifeexpectancies/bulletins/lifeexpectancyforlocalareasoftheuk/between2001to2003and2021to2023) will be uploaded when the statistical agencies of these countries provide data for the next period.
