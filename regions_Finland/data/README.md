This folder contains raw data about life expectancy from the site of [Statistics Finland](https://pxdata.stat.fi/PXWeb/pxweb/en/StatFin/StatFin__kuol/statfin_kuol_pxt_12an.px).

Download the CSV file from the site as<br>
`Select all` > `Show table` > `Save result as…` > `Tab delimited with heading`<br>
Save the file under the name `Life expectancy at birth by sex and region -Finland -2024.csv`.
