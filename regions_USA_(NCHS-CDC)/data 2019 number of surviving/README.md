This folder contains raw data for scripts work.

These data were manually copied from PDF-reports published every year by the [National Center for Health Statistics / CDC](https://www.cdc.gov/nchs/fastats/life-expectancy.htm):
* [United States Life Tables, 2019](https://www.cdc.gov/nchs/data/nvsr/nvsr70/nvsr70-19.pdf) (Volume 70, Number 19, 2022 March 22), data for different races - Tables 1-18, pages 10-45
