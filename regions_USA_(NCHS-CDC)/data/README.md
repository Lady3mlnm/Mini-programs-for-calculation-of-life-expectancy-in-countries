This folder contains raw data for scripts work.

These data were manually copied from PDF-reports published every year by the [National Center for Health Statistics / CDC](https://www.cdc.gov/nchs/fastats/life-expectancy.htm):
* [United States Life Tables, 2021](https://www.cdc.gov/nchs/data/nvsr/nvsr72/nvsr72-12.pdf) (Volume 72, Number 12, 2023 November 7), data for different races - Table 19, page 50,
* [U.S. State Life Tables, 2021](https://www.cdc.gov/nchs/data/nvsr/nvsr73/nvsr73-07.pdf) (Volume 73, Number 7, 2024 August 21), data for states - Table A, page 3,
* [United States Life Tables, 2020](https://www.cdc.gov/nchs/data/nvsr/nvsr71/nvsr71-01.pdf) (Volume 71, Number 1, 2022 August 8), data for different races - Table 19, page 51,
* [U.S. State Life Tables, 2020](https://www.cdc.gov/nchs/data/nvsr/nvsr71/nvsr71-02.pdf) (Volume 71, Number 2, 2022 August 23), data for states - Table A, page 3,
* [United States Life Tables, 2019](https://www.cdc.gov/nchs/data/nvsr/nvsr70/nvsr70-19.pdf) (Volume 70, Number 19, 2022 March 22), data for different races - Table 19, page 46,
* [U.S. State Life Tables, 2019](https://www.cdc.gov/nchs/data/nvsr/nvsr70/NVSR70-18.pdf) Volume 70, Number 18, 2022 February 10), data for states - Table A, page 3,
* [United States Life Tables, 2018](https://www.cdc.gov/nchs/data/nvsr/nvsr69/nvsr69-12-508.pdf),
* [U.S. State Life Tables, 2018](https://www.cdc.gov/nchs/data/nvsr/nvsr70/nvsr70-1-508.pdf),
* [United States Life Tables, 2017](https://www.cdc.gov/nchs/data/nvsr/nvsr68/nvsr68_07-508.pdf)
