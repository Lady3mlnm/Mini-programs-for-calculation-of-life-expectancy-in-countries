This is collection of scripts used by me for creation of tables and maps about life expectancy in Italy for the Wikipedia page "[List of Italian provinces by life expectancy](https://en.wikipedia.org/wiki/List_of_Italian_provinces_by_life_expectancy)" and its [Russian analogue](https://ru.wikipedia.org/wiki/Продолжительность_жизни_в_провинциях_Италии). I created also [alternative design](https://en.wikipedia.org/wiki/User:Lady3mlnm/List_of_Italian_provinces_by_life_expectancy_(alternative)) of the tables to explore date from a different point of view. The data is taken from the [ISTAT website](https://demo.istat.it/tavole/?t=indicatori).

Use online service [MapCharts](https://www.mapchart.net/italy.html) to create maps. But there is a difficulty in creating maps for the provinces of Italy based on data of ISTAT - you can't correctly placed to the map provinces located on the island Sardinia. The reason is that in the last decade the island has twice undergone administrative restructuring _(in 2016 and 2021)_. The online map builder MapCharts in its current state does not support the administrative division of the island, which is issued by ISTAT. I've written to the creator of MapChart but he reply that implementation of option allowing to select required version of provinces borders will required significant efforts. I've found an old version of the map builder on [web.archive.org](https://web.archive.org/web/20200524110112/https://www.mapchart.net/italy.html). It does not allow to create maps with province names, and some other options are missing, but it allows to create simple maps with the proper administrative division of Sardinia. Thus, there are options: either create province maps with province titles but remain several provinces in Sardinia uncolored, or create maps with all provinces colored but wihtout province titles. The script `Italian_maps` creates JSON-objects for both cases.
